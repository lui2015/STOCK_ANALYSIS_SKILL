# stock-analysis · 个股深度可视化分析

## 一句话介绍

输入一只股票的名字或代码，自动生成一份**可视化深度分析 HTML 报告**——包含实时快照、近五年股价中位数、近五年净利润变化、近五年总股本与市值、近五年 PE/PB/PS 估值曲线、四派圆桌讨论、操作路线图；可另出 SVG 版上传「股票精灵」平台。

---

## 如何触发

在 WorkBuddy 对话中，用以下任意方式触发：

| 触发方式 | 示例 |
|---------|------|
| `@skill:stock-analysis` + 股票名 | `@skill:stock-analysis 安克创新` |
| `@skill:stock-analysis` + 股票代码 | `@skill:stock-analysis sz300866` |
| 股票名 + 代码 | `@skill:stock-analysis 顺丰控股 002352` |
| 自然语言（需含分析意图） | "帮我分析比亚迪" / "宁德时代怎么看" |
| 报告分发 | "上传到股票精灵"（另生成 SVG 版并推送到平台） |

**不会触发**的场景：纯行情查询（"宁德现在多少钱"）、板块讨论（"新能源怎么样"）、新闻浏览。

## 输入与输出

| 项 | 说明 |
|----|------|
| **输入** | 股票名称（如"安克创新"）或代码（如"sz300866"）；可选附加关注维度 |

## 四派分析框架

| 派别 | 图标 | 核心视角 | 典型输出 |
|------|------|---------|---------|
| 🌊 产业趋势派 | 蓝色 | 产业链拆解，判断驱动力阶段和最受益环节 | 驱动力判断 + 估值硬约束 |
| 🧮 估值派 | 橙色 | PEG / PE Bands 定价，资金面校验 | 估值工具选择 + 分位 + 价格带 |
| 🔬 基本面派 | 绿色 | 财报审查，管理层评估 | 营收利润拆解 + 管理层靠谱度 |
| 📡 信号派 | 紫色 | 四层信号对齐（政策/产业/资讯/资金） | 信号状态 + 落入组合 + 建议动作 |

### 估值工具自动选择

- 盈利增速 **>20%** → PEG（PE ÷ 增速%）
- 盈利增速 **<15%** → PE Bands（5年分位 25%/50%/75%）
- 盈利为负 → PS 或其他替代指标

## 数据来源与铁律

所有数字**均来自实时查询**，不会用模型记忆数据填充：

| 数据 | 来源 |
|------|------|
| 行情 / 财报 / K线 / 资金 / 技术指标 | westock-data CLI（需先探测真实路径，见下） |
| 宏观新闻 | 财联社 API + WebSearch 备选 |
| 机构评级 / 一致预期 / 股东结构 | westock-data CLI |

> ⚠️ **CLI 路径与命令集会随版本变化**。内置路径通常不存在，需先探测（常见位置：`~/.npm/_npx/*/node_modules/westock-data-skillhub/index.js`），
> 用受管 node 执行，并先跑 `--help` 确认命令集。本版本**无 `quote` / `news` / `risk`**，最新价一律用 `kline` 取。

**数据铁律**：
1. 先查后写——所有数字有对应查询动作
2. PE 交叉验证——数据源 PE(TTM) vs 自算 PE，偏差>5% 必须查口径而不是改数字
3. 时效标注——盘后 2 小时以上必须标"数据截止"
4. 异常主动提——PE 为负、机构覆盖<3家、股东户数暴增等
5. 货币单位——港股港元 / 美股美元 / A股人民币，不混用符号
6. **股本口径一致**——PE 用加权平均股本，PB/PS 用期末总股本
7. **拐点优先**——年度增速好看但最新单季转负时，以单季为准并高亮

## 技术要点

- **Canvas 兼容性**：所有 Canvas 绘制代码需包裹在 `window.addEventListener('load', ...)` 中，并添加 `roundRect` polyfill（部分 WebView 不支持原生 API）
- **平台上传改用 SVG**：股票精灵等平台可能过滤 `<script>`，Canvas 会被整片清空，必须改用**内联 SVG**（纯静态标记，100% 渲染）
- **涨跌颜色**：遵循中国市场惯例——**涨红跌绿**（与美股惯例相反）
- **DPR 适配**：Canvas 绘制使用 `devicePixelRatio` 缩放，确保 Retina 屏清晰
- **响应式**：HTML 报告使用 CSS Grid + 媒体查询适配移动端

### 已知坑位（SKILL.md 已内置解法）

| 坑 | 表现 | 解法 |
|----|------|------|
| A 股 K 线 250 根上限 | `--limit 1260` 只回 ~250 根，**不报错** | 按年分段抓后 `sort -u` 合并，核对根数 >1200 |
| A 股财报字段名 | 照抄港股字段名取到空值 | 用 `EndDate.endswith('12-31')` 筛年报；毛利率/ROE/负债率自行计算 |
| PE 股本口径 | 自算 PE 与数据源差 5% | PE 用加权平均股本（累计净利÷累计 EPS），PB/PS 用期末总股本 |
| 年度数据掩盖拐点 | 全年 +9% 但 Q2 单季 -15% | 必须单独挑出最新报告期的单季/半年同比并高亮 |
| 平台图表消失 | 上传后只剩文字表格 | 改用内联 SVG，且图表数量不能缩水 |

## 注意事项

- 完整分析约需 2-3 分钟（15+ 次数据查询 + HTML 生成）
- 支持 A 股、港股、美股，自动匹配对应资金查询命令（注意 `rating` 仅港股美股、`fund margin` 仅 A 股）
- 报告末尾包含免责声明，**不构成投资建议**
- 本 Skill 依赖 westock-data 提供实时行情数据
